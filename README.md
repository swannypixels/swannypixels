# Hey there! 👋

Hi, I'm **Richard**, also known as **swanny**. I make event posters, brand visuals and custom websites, and I usually design and build them end to end, so nothing gets lost between the mockup and the browser.

These days I work on projects at [**NXTHING.EU**](https://www.nxthing.eu), with the motto *"We bring your ideas to life."*

### What I do

- **Graphic design:** event posters, brand identities, social visuals
- **Web development:** custom full-stack websites and web apps, mostly in Svelte and TypeScript
- **Tools & plugins:** small utilities in Python, and Spigot plugins in Java
